# Grid Shift direction correction

- Grid Shift now makes the puzzle easier by reducing the square grid by one or two levels.
- Examples: 4x4 -> 3x3 or 2x2; 6x6 -> 5x5 or 4x4; 8x8 -> 7x7 or 6x6.
- The same puzzle image is used; fewer cells create larger pieces.
- Entering the reduced grid costs 1 Crystal.
- Restore Grid returns to the Adventure's original grid for free.
- Grid Shift never goes below 2x2.
- Completion begins at 0% on the rebuilt grid, and timer/targets restart for that attempt.
