Ocean progress controls update

- Removed the standalone Completion percentage/progress panel from active gameplay.
- The four gameplay controls now act as the progress indicator.
- Puzzle completion fills each control from bottom to top with an animated ocean-water effect.
- The water surface continuously moves with a wave/shimmer animation.
- The control tray uses a dark lavender background for stronger contrast.
- Existing vibrant press/bounce/sparkle behavior is preserved.
- Completion percentage remains available in accessibility descriptions but is no longer shown as a separate visual bar.
- No third-party animation library is required.
