# Automatic timer update

- The Adventure timer starts automatically as soon as the puzzle is ready on screen.
- There is no Start state/button anymore.
- The first bottom control is Pause while running and Resume while paused.
- Pausing freezes both the timer and puzzle interaction; Resume continues from the same elapsed time.
- Restart immediately begins a new timed attempt at 00:00 after confirmation.
- Grid Shift / Restore immediately begins the rebuilt puzzle at 00:00.
- Opening a saved unfinished Adventure automatically resumes timing from its saved elapsed time.
- Opening the photo attribution no longer pauses the timer.
