# Bottom puzzle controls

The puzzle now uses exactly four compact controls below the completion bar:

1. Timer — Start/Pause/Resume.
2. Grid — spends one Crystal to shift harder; Restore is free.
3. Hint — moves one current block/group into its correct location and counts as one move.
4. Restart — confirms and restarts the current Adventure.

Hint is disabled while the timer is deliberately paused.
## Random Hint Selection

Each Hint now chooses randomly from the currently unsolved loose pieces or merged groups. There is no fixed top-to-bottom, bottom-to-top, row, or column solving order. A connected group remains rigid and moves as one visual block.
